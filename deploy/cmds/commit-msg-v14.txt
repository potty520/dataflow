feat(v1.4): FTP 文件迁移 + 跨网络数据迁移（代理隧道）

远程数据源（跨网络）
- 新增 mig_datasource：MySQL/PostgreSQL 远程库，密码 AES-GCM 加密存储
- 代理支持：DIRECT / SOCKS5 / HTTP CONNECT，ProxyTunnel 零依赖手工握手 + 本地端口转发
- 连接测试（返回耗时/版本）、远程字段探测（MySQL/PG 兼容）、未保存配置临时测试
- 迁移项目新增 source_ds_id / target_ds_id，支持 远程→本地、本地→远程、远程↔远程（经本地中转）

跨库迁移执行（CrossMigrationService）
- 源连接流式读 → 目标连接批量写（500/批），全量/增量、分批、断点续传

FTP 文件迁移
- mig_file_task / mig_file_run：方向 EXPORT/IMPORT、CSV（可 gzip）、FTP 上传/下载、SHA-256 校验
- 支持经 SOCKS5/HTTP 代理访问 FTP（自定义 SocketFactory，控制+数据连接均走隧道）
- 导出复用迁移项目映射（列名/表达式），导出文件可原样导入同项目目标表
