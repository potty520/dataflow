# 业务域拆分 · 元数据服务

## 形态

| 项 | 说明 |
|---|---|
| 服务 | `dgp-metadata` |
| 端口 | **8083** |
| 网关路径 | `/api/v1/metadata/**` |
| 库 | 与 core/auth 共用 H2/MySQL（`DGP_H2_FILE`） |

## 绞杀策略

- **已迁出**：`MetadataController`（对外 API 全部走 metadata 服务）
- **暂留 core**：`MetaCollectService` / `LineageService`（供 SeedRunner、内置/内部调度、建模影响分析调用）
- 后续可将采集/血缘内部调用改为 HTTP，再删除 core 内副本

## 启动

`start-microservices.cmd` 已包含 metadata。Compose 服务名：`metadata`。

```bash
mvn -DskipTests package -pl dgp-metadata -am
java -jar dgp-metadata/target/dgp-metadata.jar
```

冒烟会检查直连 `8083/actuator/health` 与网关 `/api/v1/metadata/tables`。
