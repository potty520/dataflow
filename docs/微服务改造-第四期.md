# 微服务改造 · 第四期（海量检索 / Elasticsearch）

## 能力

- 统一检索入口：`GET /api/v1/search?keyword=&types=TABLE,ASSET,STANDARD,API`
- 默认 **本地内存索引**（无 ES 可跑）；设 `DGP_ES_ENABLED=true` 切 Elasticsearch 8
- Outbox：`sys_search_outbox`（Flyway V3）；元数据写路径投递，search 每 15s 消费
- 前端 `metadataApi.search` / `assetApi.search` 优先打 search 服务，失败回退原 SQL LIKE

## 环境变量

| 变量 | 说明 |
|---|---|
| `DGP_ES_ENABLED` | `true` 启用 ES |
| `DGP_ES_URIS` | 默认 `http://127.0.0.1:9200` |
| `DGP_ES_INDEX` | 索引名，默认 `dgp_catalog` |
| `DGP_SEARCH_REINDEX_ON_START` | 启动全量重建，默认 true |
| `DGP_H2_FILE` | 与 core 共用库 |

## Compose

```bash
# 仅本地索引
docker compose -f deploy/compose/docker-compose.yml up -d search

# 启用 ES
docker compose -f deploy/compose/docker-compose.yml --profile es up -d elasticsearch
# 然后 DGP_ES_ENABLED=true 启动 search
```

## API

- `GET /api/v1/search` — 检索（需 `metadata:search`）
- `GET /api/v1/search/status` — 引擎与文档数
- `POST /api/v1/search/reindex` — 全量重建（需配置编辑权限）
