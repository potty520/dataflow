# 业务域拆分 · 质量服务

## 形态

| 项 | 说明 |
|---|---|
| 服务 | `dgp-quality` |
| 端口 | **8087** |
| 网关路径 | `/api/v1/quality/**` |
| 库 | 与 core 共用（`DGP_H2_FILE`） |

## 绞杀策略

- **已迁出**：`QualityController` / `QualityConfigController` / `StreamQualityController` / `StreamQualityService` / 质量侧 `ReportService` 副本
- **暂留 core**：`QualityEngine`（SeedRunner、内置/内部调度 `runCheck`）
- 流式质检 `@Scheduled` 微批改在 quality 进程内跑

## 启动

```bat
mvn -DskipTests package -pl dgp-quality -am
start-microservices.cmd
```

冒烟：`verify\smoke_microservices.ps1` 含直连 8087 与网关 `/api/v1/quality/rules`。
