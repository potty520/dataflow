# 业务域拆分 · 迁移服务

## 形态

| 项 | 说明 |
|---|---|
| 服务 | `dgp-migration` |
| 端口 | **8088** |
| 网关路径 | `/api/v1/migration/**` |
| 库 | 与 core 共用（`DGP_H2_FILE`） |

## 绞杀策略

- **已迁出**：`MigrationController` / `AggregationController` / `RemoteDsController` / `FileMigrationController`，以及 migration 进程内的服务副本与 `TypeMappingService`
- **暂留 core**：`AggregationService` / `MigrationService` / `RemoteDsService` / `CrossMigrationService` / `FileMigrationService` / `FtpTransferService` / `ProxyTunnel`（内置调度与 `InternalSchedulerController` 仍调用聚合汇总）
- 对外 HTTP 一律经网关到 8088；core 不再暴露 migration Controllers

## 启动

```bat
mvn -DskipTests package -pl dgp-migration,dgp-core,dgp-gateway -am
start-microservices.cmd
```

冒烟：`verify\smoke_microservices.ps1` 含直连 8088 与网关 `/api/v1/migration/projects`。
