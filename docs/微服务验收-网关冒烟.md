# 微服务验收 · 网关冒烟

所有验收脚本的 `-Base` **默认且必须**指向网关 `http://127.0.0.1:8080`，不要直连 `core:8082`。

## 前置

```bat
docker compose -f deploy\compose\docker-compose.yml up -d redis
build.cmd
start-microservices.cmd
```

等 core 种子完成（约 1 分钟）后再跑脚本。

## 推荐命令

```powershell
# 仅微服务探针（健康、RS256/JWKS、经网关路由 search/scheduler/security）
.\verify\smoke_microservices.ps1 -Base http://127.0.0.1:8080

# 冒烟 + 根目录 verify.ps1
.\verify\run_gateway_suite.ps1 -Base http://127.0.0.1:8080

# 全量 flows（慢）
.\verify\run_gateway_suite.ps1 -Base http://127.0.0.1:8080 -Full
```

单独脚本与改造前相同，例如：

```powershell
.\verify.ps1 -Base http://127.0.0.1:8080
.\verify\flows_tenant.ps1 -Base http://127.0.0.1:8080
```

## 冒烟覆盖点

| 检查 | 说明 |
|---|---|
| 直连 health | auth/core/security/search/scheduler |
| 网关 ping | `/api/v1/admin/ping` |
| JWKS + RS256 | `/api/v1/auth/jwks`，JWT header `alg=RS256` |
| 路由 | overview / search / scheduler / audit/chain |
| 无令牌 401 | 网关拦截 |
| 登出吊销 | 需 Redis 时跨实例一致 |

失败时优先查：服务是否都起来、Redis 是否可达、`DGP_H2_FILE` 是否共用、种子是否完成。
