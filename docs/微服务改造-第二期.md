# 微服务改造 · 第二期（多租户 + 合规）

## 已落地

### 租户隔离
- `TenantGuard` 严格模式默认开启（`dgp.tenant.strict=true`）
- 非平台管理员禁止 `/*tenant:off*/`
- 复杂 JOIN/UNION 且未显式带 `tenant_id` 时直接失败
- 单测：`dgp-common/src/test/java/com/dgp/common/TenantGuardTest.java`

### 租户配额
- 表 `sys_tenant_quota`（Flyway `V2__tenant_quota_and_password_policy.sql`）
- `TenantQuotaService` 同步到 Redis：`dgp:quota:tenant:{id}:rpm|daily`
- 网关按租户 RPM + 日配额限流
- 管理接口：`GET/PUT /api/v1/admin/tenant-quotas`

### 审计防篡改
- `Db.update/delete` 禁止改写 `sec_audit_log` / `sec_audit_chain`
- `dgp-security:8084` 独立提供：
  - `GET /api/v1/security/audit/chain`
  - `POST /api/v1/security/audit/verify`（及 `verify-chain`）
- 网关将上述路径路由到 security 服务

### 强制改密
- `sys_user.must_change_password` / `password_changed_at`
- JWT 声明 `mcp=1`；网关拦截除改密/登出/me/menus 外的访问
- 管理员重置口令会置 `must_change_password=1`

## 启动提示

```bat
set DGP_REDIS_ENABLED=true
set DGP_H2_FILE=%CD%\data\dgp
REM core -> auth -> security -> gateway
```
