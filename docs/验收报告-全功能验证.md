## 4. 业务链路验证（220 项断言）

### A. 认证与 RBAC（24 项）

### B. 元数据（25 项）

### C. 建模（11 项）

### D. 标准（9 项）

### E. 集成与加工（21 项）

### F. 调度与工作流（7 项）

## 6. 验收中发现并修复的缺陷

| # | 缺陷 | 影响 | 修复 |
|---|---|---|---|
| 1 | `DELETE /model/models/{id}` 返回 500 | 草稿模型无法删除 | 子查询缺右括号 `... model_id=?)`；已修 |
| 2 | 唯一约束冲突（如重复数据元编码）返回 500 | 用户看到"系统异常"而非明确提示 | 新增 `DuplicateKeyException` 全局处理 → 400；数据元编码增加前置校验 |
| 3 | 血缘解析接受 `DELETE`/DDL 语句并返回空结果 | 语义误导 | 仅允许 SELECT/INSERT...SELECT，其余 400 并说明 |
| 4 | 错误 `Content-Type` 返回 500，错误 HTTP 方法返回 500 | 排障困难 | 分别返回 415 / 405 |
| 5 | 分析师缺少 `asset:value:view` | 资产价值依据页 403、页面空白 | 角色权限补授（重启自动同步） |
| 6 | 行业顾问有"数据质量"菜单但缺 5 个只读权限 | 质量页 KPI 全空（显示 `-`/0%） | 补授 score/check/overview/issue/report 只读权限 |
| 7 | 浏览器偶发 `ERR_INVALID_CHUNKED_ENCODING`（约 8% XHR） | 个别请求被浏览器丢弃、页面局部空 | 服务端本机 240 次请求 0 截断，定位为公网链路对 chunked 处理不规范；新增 `ContentLengthFilter` 改为定长响应 + 前端 GET 网络失败自动重试；复测 30 次页面加载 0 失败 |

## 7. 遗留与建议

1. **多租户行级隔离**未注入 SQL（当前仅租户字段与菜单隔离），上生产前建议在 `Db`/拦截器层统一注入租户条件。
2. **单机 1 vCPU / 2GB** 与 4 个其他 Java 服务共用，ETL 全量作业耗时约 0.2~8s/个；若并发用户增多建议升配或把 ETL 拆到独立节点。
3. 演示账号口令统一（`Dgp@2026`）且公网可访问，建议仅内网开放或加 IP 白名单 + HTTPS 反代（已支持 `DGP_CORS_ORIGINS`）。
4. 未接入外部调度器/ES/图数据库，`/workflow/sync/*` 已如实返回"不支持"，不产生假成功。
5. 演示数据为 MySQL 库 `dgp`（97MB）；备份命令见 README §11.5。
