# 微服务改造 · 第一期（平台底座）

## 已落地

| 模块 | 端口 | 说明 |
|---|---|---|
| `dgp-common` | - | Result/Db/TenantGuard/PasswordUtil/MenuCatalog/网关 HMAC |
| `dgp-gateway` | 8080 | Spring Cloud Gateway，RS256 验签、租户限流、内部身份头 |
| `dgp-auth` | 8081 | 登录/刷新/登出、JWKS、Redis jti 黑名单（可关） |
| `dgp-core` | 8082 | 原业务域过渡态（Flyway + 演示种子） |
| `dgp-metadata` | 8083 | 元数据（绞杀拆分） |
| `dgp-security` | 8084 | 审计链校验（二期） |
| `dgp-search` | 8085 | 统一检索 / 可选 ES（四期） |
| `dgp-scheduler` | 8086 | 本地扫描 / XXL 执行器（三期） |
| `dgp-quality` | 8087 | 质量（绞杀拆分） |
| `dgp-migration` | 8088 | 迁移（绞杀拆分） |

基础设施编排：[`deploy/compose/docker-compose.yml`](../deploy/compose/docker-compose.yml)（MySQL/Redis/Nacos/Prometheus/Grafana + 应用）。

## 本地最小启动（H2，可不启 Nacos）

```bat
REM 需要 JDK 17
set JAVA_HOME=%USERPROFILE%\.jdks\ms-17.0.18
mvn -DskipTests package -pl dgp-common,dgp-gateway,dgp-auth,dgp-core -am

REM 建议 Redis（登出黑名单/限流）；没有也能跑，限流与吊销降级
docker compose -f deploy\compose\docker-compose.yml up -d redis

start-microservices.cmd
```

浏览器访问网关：`http://127.0.0.1:8080`（core 静态资源）或前端 `npm run dev`（已代理到 8080）。

演示账号仍为 `admin` / `Dgp@2026`。

## 环境变量（生产必改）

- `DGP_GATEWAY_HMAC_SECRET`：网关与下游共享 HMAC
- `DGP_JWT_PRIVATE_KEY` / `DGP_JWT_PUBLIC_KEY`：PEM；缺失时 auth 本地生成（仅开发）
- `DGP_REDIS_ENABLED=true` + `DGP_REDIS_HOST`
- `DGP_NACOS_ENABLED=true` + `DGP_NACOS_ADDR`（可选）
- `DGP_MASK_KEY`：脱敏密钥（core）
